# JEE Ascension V4

Highly customizable JEE tracker.

Features:
- Command Center with next-action priority, adaptive capacity and Minimum Viable Day.
- Editable To-Do: add, edit name/description/XP, complete/undo, delete, reorder.
- Progress Board with all current Maths/Physics/Chemistry deadlines.
- Missed deadline -> automatic backlog + one-time XP penalty.
- Test Hub with test readiness and current test-prep tasks.
- Weakness Bank with mistake types and fix quests.
- Course Library / YouTube Launchpad for exact video URLs.
- Revision scheduler with custom intervals.
- Lightweight Question Log.
- Ascension stats and mistake patterns.
- End-of-day review.
- Settings for navigation, workload, penalties, resource lock, overthinking nudge, theme and revision intervals.
- Browser localStorage; JSON export stays private.

Upload the three site files to a public GitHub Pages repository. Do not upload exported JSON backups.
